# Screenshots

Add final portfolio screenshots here after the web application is deployed.

Recommended screenshots:

1. Desktop weather dashboard
2. Search result for a city
3. Five-day forecast
4. Recent searches
5. Celsius/Fahrenheit switch
6. Mobile responsive layout
7. Java Swing academic version

Use descriptive filenames such as:

- `desktop-dashboard.png`
- `forecast.png`
- `recent-searches.png`
- `mobile-dashboard.png`
- `java-desktop.png`

Do not place API keys, credentials, personal information, or private deployment settings in screenshots.
