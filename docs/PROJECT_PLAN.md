# Project Plan

## Phase 1 — Academic Preservation

Keep the Java Swing implementation recognizable as the CS 1103 Programming 2 activity. Remove the exposed API key and load it through an environment variable.

## Phase 2 — Full-Stack Recreation

Build a responsive browser interface with the same core concepts and a richer presentation inspired by the assignment screenshot.

## Phase 3 — Backend

Create a Spring Boot REST service that accepts a city and unit, resolves the city through Open-Meteo geocoding, retrieves current conditions and a five-day forecast, and returns a clean application-specific JSON response.

## Phase 4 — Testing

Run Maven unit tests, verify API responses locally, test invalid cities, test both temperature units, and check responsive layouts.

## Phase 5 — Deployment

Deploy the Spring Boot API on Render and the Vite frontend on Vercel. Configure CORS and the frontend API URL through deployment environment variables.

## Phase 6 — Portfolio

Add screenshots, GitHub repository link, live demo link, architecture diagram, and a concise project description to the user's portfolio.
