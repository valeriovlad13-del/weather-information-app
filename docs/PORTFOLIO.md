# Portfolio Entry

## Weather Information App

**Java · Spring Boot · JavaScript · REST API · JSON · Vite · Responsive Web Design**

A full-stack recreation and extension of a University of the People CS 1103 Programming 2 weather application. The project preserves the academic Java Swing implementation while extending the same core requirements into a responsive web application with a Spring Boot REST backend.

### Key Features

- City-based weather search
- Current weather information
- Celsius/Fahrenheit switching
- Five-day forecast
- Recent-search history
- Responsive design
- REST API and JSON mapping
- Open-Meteo geocoding and forecast integration
- CORS configuration
- Health endpoint
- Automated backend tests and frontend build verification
- Environment-based configuration

The project includes a Java Swing academic version and a modern web version using Vite, JavaScript, Spring Boot, REST APIs, and Open-Meteo. I implemented city search, unit conversion, five-day forecasts, recent-search history, API error handling, CORS configuration, automated tests, and deployment-ready configurations for Vercel and Render.

### Technical Highlights

**Frontend:** Vite, HTML, CSS, JavaScript, localStorage

**Backend:** Java 21, Spring Boot, REST API, Jackson, CORS, Actuator

**Desktop:** Java 21, Swing, Weatherstack, org.json

**Deployment:** Vercel for the frontend and Render for the backend

**Testing:** Maven tests plus GitHub Actions CI

### What This Project Demonstrates

- Translating an academic desktop application into a full-stack web architecture
- Separating frontend presentation from backend API responsibilities
- Integrating third-party REST services
- Handling asynchronous API requests and error states
- Managing environment variables without exposing credentials
- Preparing an application for production deployment
- Using automated CI to catch build and test failures
