# Portfolio Entry

## Weather Information App

**Java · Spring Boot · JavaScript · REST API · JSON · Vite · Responsive Web Design**

A full-stack recreation of a University of the People CS 1103 Programming 2 weather application. The project preserves the original Java Swing implementation while extending the concept into a responsive web application with live weather search, unit conversion, five-day forecast data, recent searches, API error handling, and production-style deployment.
